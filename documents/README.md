# Knowledge base

Design specs for Dice RPG, organized by system pillar. Each folder owns one system end-to-end, with an `overview.md` + split detail files.

Dice RPG is **closely inspired by Dokapon Kingdom**, free to diverge on numbers and content. Specs describe what *our* game does; Dokapon references appear as margin notes ("Dokapon reference: ...") pointing to raw research in `../sources/`.

## Pillars

| Folder | Scope |
|---|---|
| [board/](board/overview.md) | Space types, layout, movement, dice, turn structure |
| [combat/](combat/overview.md) | RPS battle system, stats, damage, status effects |
| [characters/](characters/overview.md) | Levels, jobs, EXP, mastery, stat growth, skills |
| [equipment/](equipment/overview.md) | Weapons, shields, armor, accessories, magic books |
| [items/](items/overview.md) | Field items, consumables, sabotage tools |
| [magic/](magic/overview.md) | Spells, elements, resistances, field vs battle magic |
| [towns/](towns/overview.md) | Liberation, taxation, upgrades, local items, castles |
| [world/](world/overview.md) | Continents, NPCs, monsters, story, world objects |
| [meta/](meta/overview.md) | Modes, win conditions, session structure, multiplayer |
